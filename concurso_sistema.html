Importar questões

Importe um arquivo JSON com questões. Pode mesclar com o banco atual ou substituir.

Formato JSON esperado
Cada questão deve ter os seguintes campos. Campos marcados com * são obrigatórios. 
{
  "questions": [
    {
      "concurso": "SETEC 2026",          // * nome do concurso
      "disciplina": "Direito Administrativo", // * disciplina
      "subtopico": "Impessoalidade",     // * sub-tópico específico
      "dificuldade": "facil",            // * facil | medio | dificil
      "enunciado": "Texto da questão...",// * enunciado completo
      "alternativas": {
        "A": "Texto alternativa A",      // *
        "B": "Texto alternativa B",      // *
        "C": "Texto alternativa C",      // *
        "D": "Texto alternativa D",      // *
        "E": "Texto alternativa E"       // opcional
      },
      "gabarito": "B",                   // * letra correta
      "explicacao_correta": "Por que B está correta...", // *
      "explicacoes_alternativas": {
        "A": "Por que A está errada...", // recomendado
        "C": "Por que C está errada...", // recomendado
        "D": "Por que D está errada...", // recomendado
        "E": "Por que E está errada..."  // recomendado
      },
      "dica_visual": ""                  // opcional, para Matemática/Lógica
      "nota_pessoal": ""                 // anotação sua (preenchida durante o estudo)
    }
  ]
}
